# [Word] Chỉnh sửa tài liệu

## Chuẩn bị
Chưa mở đúng file → làm theo skill mở file. Thấy Protected View thì bật chỉnh sửa.

## Thay hoặc xoá một đoạn chữ (cách chắc nhất)
1. `hotkey ctrl+h` → `screenshot` thấy hộp Tìm và Thay thế, con trỏ ở ô Tìm.
2. `hotkey ctrl+a` → `type <chữ cần tìm>` → `key tab` → `hotkey ctrl+a`.
3. Để thay: `type <chữ mới>`. Để xoá: `key delete`, để trống ô thay thế.
4. `tap` keywords ["Thay thế Tất cả", "Replace All"]. Chỉ muốn sửa chỗ đầu tiên thì
   `tap` keywords ["Thay thế", "Replace"].
5. `screenshot` đọc số chỗ đã thay → `key enter` đóng thông báo → `key esc` đóng hộp.
   Báo 0 chỗ: dừng và báo không tìm thấy chữ đó.

## Thêm nội dung
- Cuối tài liệu: `hotkey ctrl+end` → `key enter` → `type`.
- Đầu tài liệu: `hotkey ctrl+home` → `type` → `key enter`.
- Giữa tài liệu: cuộn tới chỗ cần sửa, `tap` keywords ["<chữ của dòng đó>"] → `key end`
  → `key enter` → `type`.

## Định dạng
- Chữ sắp gõ: `hotkey ctrl+b` / `ctrl+i` / `ctrl+u` → `type` → bấm lại để tắt.
- Toàn bộ tài liệu: `hotkey ctrl+a` → phím định dạng → `hotkey ctrl+home`.
- Không có công cụ bôi đen một cụm chữ bất kỳ: gặp yêu cầu định dạng đúng một cụm thì
  báo người dùng là chưa làm được.

## Kết thúc
1. `screenshot` kiểm tra kết quả; sai thì `hotkey ctrl+z`.
2. `hotkey ctrl+s` → `screenshot`. Word hỏi định dạng hoặc tên file thì đọc kỹ, không
   tự ghi đè file khác.
3. Báo đã sửa gì và đã lưu vào file nào.

## Quy tắc
- Chỉ sửa đúng phần được yêu cầu.
- Không dùng `ctrl+a` trong trang rồi gõ: thao tác đó xoá toàn bộ tài liệu.
- Không gõ dấu xuống dòng trong `type`.
