# [Word] Mở một file tài liệu

## Quy trình
1. `screenshot` TRƯỚC TIÊN. Thanh tiêu đề Word đã ghi đúng tên file → xong, KHÔNG mở
   lại (ngữ cảnh nói đã mở trước đó thì vẫn phải thấy trên ảnh).
2. Chỉ có tên file → làm theo skill **tìm và mở file bằng Windows Search** (`win+s`).
3. Có đường dẫn đầy đủ:
   - Đang có Word: `hotkey ctrl+f12` → `type <đường dẫn>` → `key enter`.
   - Chưa có Word: `hotkey win+r` → `type <đường dẫn>` → `key enter`.
4. `screenshot` xác minh thanh tiêu đề ghi đúng tên file. Word mở chậm thì chụp lại
   tối đa 2 lần.
5. Cần sửa mà thấy dải "Protected View": bấm "Cho phép Chỉnh sửa / Enable Editing".

## Khi có sự cố
- File đang khoá hoặc "read-only": báo người dùng, không tự lưu đè bản khác.
- Báo không tìm thấy hoặc lỗi file: dừng và báo đúng thông báo trên màn hình.
- Không chạy file `.exe`, `.bat`, `.ps1` hay macro; thấy cảnh báo macro thì KHÔNG bật.
