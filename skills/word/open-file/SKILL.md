# [Word] Mở một file tài liệu

## Quy trình
1. `screenshot`. Thanh tiêu đề Word đã ghi đúng tên file → xong.
2. Mở file:
   - **File đang hiện trong danh sách** (sau khi tìm): `tap` keywords ["<tên file đúng
     như trên ảnh>"], rồi `key enter`.
   - **Có đường dẫn, đang có Word:** `hotkey ctrl+f12` → `type <đường dẫn đầy đủ>` →
     `key enter`.
   - **Có đường dẫn, chưa có Word:** `hotkey win+r` → `type <đường dẫn đầy đủ>` →
     `key enter`.
   - **Chỉ có tên file:** làm theo skill tìm file trước.
3. `screenshot` xác minh thanh tiêu đề ghi đúng tên file. Word mở chậm thì chụp lại
   tối đa 2 lần.
4. Cần sửa mà thấy dải "Protected View": bấm "Cho phép Chỉnh sửa / Enable Editing".

## Khi có sự cố
- File đang khoá hoặc "read-only": báo người dùng, không tự lưu đè bản khác.
- Báo không tìm thấy hoặc lỗi file: dừng và báo đúng thông báo trên màn hình.
- Không chạy file `.exe`, `.bat`, `.ps1` hay macro; thấy cảnh báo macro thì KHÔNG bật.
