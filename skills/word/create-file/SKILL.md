# [Word] Tạo tài liệu mới

## Quy trình
1. `screenshot`. Đang có Word: `hotkey ctrl+n`. Chưa có: `hotkey win+s` → `type Word` →
   `key enter` → `screenshot`, rồi `hotkey ctrl+n` hoặc `tap` keywords ["Tài liệu trống",
   "Blank document"].
2. `screenshot` xác minh có trang trắng.
3. Gõ lần lượt từng đoạn: `type <một đoạn>` → `key enter`. Mỗi đoạn một lần `type`,
   dài đến đâu cũng được.
   - Tiêu đề: `hotkey ctrl+alt+1` (cấp 2, 3 dùng `ctrl+alt+2`, `ctrl+alt+3`) rồi `type`
     rồi `key enter`.
   - Đậm/nghiêng cho chữ sắp gõ: `hotkey ctrl+b` → `type` → `hotkey ctrl+b` để tắt.
   - Sang trang mới: `hotkey ctrl+enter`.
4. Lưu: `hotkey f12` → `screenshot` thấy hộp Lưu thành, con trỏ ở ô tên file →
   `type <tên file>` (hoặc đường dẫn đầy đủ nếu người dùng nêu thư mục) → `key enter`.
5. `screenshot` xác minh thanh tiêu đề ghi tên file mới.

## Quy tắc
- Người dùng không đặt tên: tự đặt tên ngắn theo nội dung và báo lại tên, thư mục.
- Word hỏi có thay thế file đã có: `ask_user` với lựa chọn ["Ghi đè", "Đặt tên khác"],
  không tự ghi đè.
- Gõ đúng nội dung được yêu cầu. Yêu cầu chỉ nêu chủ đề thì tự soạn ngắn gọn.
- Không gõ quá dài trong một tác vụ: mỗi đoạn tốn một lượt `type` và một lượt `enter`.
