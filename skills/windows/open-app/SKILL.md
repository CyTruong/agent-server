# [Windows] Mở ứng dụng / file / thư mục

## Quy trình
1. `screenshot` xem trạng thái hiện tại; nếu app đã mở sẵn thì dùng luôn.
2. Mở app theo tên: `key win` (cần xác nhận) → `type <tên app>` (vd "notepad",
   "chrome") → `key enter` → `screenshot` xác nhận cửa sổ đã mở.
3. Mở theo đường dẫn: `hotkey win+r` (cần xác nhận) → `type <đường dẫn đầy đủ>` →
   `key enter`. Windows mở file bằng app mặc định, hoặc mở thư mục trong Explorer.
4. Mở bằng Explorer: `hotkey win+e` → điều hướng → `tap` vào file (keywords = tên file).
5. `screenshot` xác minh đã mở đúng.

## Quy tắc
- Chỉ mở đúng thứ người dùng yêu cầu; không chạy file lạ hay file thực thi đáng ngờ.
- Đường dẫn sai / báo lỗi trên ảnh: dừng và báo người dùng.
