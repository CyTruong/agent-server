# [Windows] Điều hướng trình duyệt

## Quy trình
1. `screenshot`; chưa có trình duyệt thì mở Chrome (skill mở ứng dụng).
2. Tới địa chỉ: `hotkey ctrl+l` → `type <URL hoặc từ khoá>` → `key enter`.
3. Chờ trang tải rồi `screenshot`; đọc nội dung trước khi bấm tiếp.
4. Bấm liên kết/nút: `tap` với keywords = chữ của liên kết/nút.
5. Cuộn: `scroll` âm để xuống, dương để lên; chụp lại giữa các lần cuộn.
6. Tab mới / đóng tab: `hotkey ctrl+t` / `ctrl+w`.

## Quy tắc
- Trang web tải không tức thì: luôn chụp lại sau khi điều hướng, đừng bấm mù.
- Không tải/chạy file lạ, không bấm quảng cáo/pop-up; gặp pop-up thì chụp và hỏi.
